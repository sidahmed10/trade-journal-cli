# 📊 Mini Trade & Performance Journal CLI

A lightweight command-line utility written in Python to parse trade logs, calculate core performance metrics, and generate an instant trading performance report.

## Features
- Reads raw trade execution data from a CSV file.
- Automatically computes **Total Trades**, **Winning Trades**, **Win Rate (%)**, and **Net PnL ($)**.
- Clean terminal-based summary dashboard.

## Requirements
- Python 3.x

## How to Run
1. Clone this repository or download the files.
2. Ensure your `trades.csv` is in the same directory.
3. Run the script:
   ```bash
   python3 tradingjournal.py
